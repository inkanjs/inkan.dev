---
title: "Context"
description: "ctx: everything a handler, a hook and a middleware get about their request."
---

```ts
app.get("/teas/:id", { params: t.object({ id: t.int() }) }, (ctx) => {
  ctx.header("cache-control", "max-age=60");
  return findTea(ctx.params.id);
});
```

Every handler gets the context of its request. It can be taken apart,
`({ params, header }) => …`, and every part of it still works: the functions on it need no
`this`. Nothing on it is made before it is asked for, so what a handler does not use costs
nothing.

## params, query, headers, body

```ts
app.post("/teas/:shop", { params: t.object({ shop: t.string() }), body: NewTea }, ({ params, body }) =>
  store.add(params.shop, body),
);
```

The input, checked and typed by the route's schemas. Without a schema they are the request's
own values, as text.

## method, path, url

```ts
({ method, path, url }) => `${method} ${path} on ${url.host}`
```

The request line. `url` is a `URL`, made only when it is read.

## id

```ts
({ id }) => logger.info({ id }, "tea added")
```

The request id: the one in `x-request-id` when it looks safe, a fresh one otherwise. It goes
back out as a header and sits in every log line and in every problem document, so a bug
report points at the right line.

## ip

```ts
({ ip }) => ({ you: ip })
```

The client's address, as the socket or the platform says it. Behind a proxy that is the
proxy; read its `x-forwarded-for` yourself when you trust it.

## cookies <small>0.7.0</small>

```ts
({ cookies }) => sessions.get(cookies.sid)
```

The request's cookies, by name, decoded. Read on first use.

## signal <small>0.7.0</small>

```ts
app.get("/report", { timeout: 600_000 }, ({ signal }) => db.query(REPORT, { signal }));
```

An `AbortSignal` that aborts when the client goes away before the answer is out, or when the
route's `timeout` runs out. Hand it to the database driver or to `fetch`, and work nobody
waits for any more stops.

## state

```ts
app.use(async (ctx, next) => {
  ctx.state.user = await userFrom(ctx.headers.authorization);
  await next();
});
```

Free space for middleware to hand things on to the handler. For values that are the same on
every request, a [decoration](/docs/api/app#decorate) is cheaper.

## route

```ts
({ route }) => metrics.count(route?.path) // "/teas/:id", not "/teas/7"
```

The route that matched, as it was written.

## req, res

Node's request and response, when the request came through a socket. Writing to `res`
yourself is allowed; inkan then leaves the answer alone.

## status()

```ts
({ status }) => {
  status(202);
  return { queued: true };
};
```

The status a plain value answers with.

## header()

```ts
({ header }) => {
  header("cache-control", "no-store");
  return data;
};
```

A header on the answer.

## reply()

```ts
app.post("/teas", { body: NewTea, response: { 201: Tea } }, ({ body, reply }) => {
  const tea = store.add(body);
  return reply(201, tea, { location: `/teas/${tea.id}` });
});
```

Another status, with extra headers if needed. It is typed to the statuses the contract
lists, so `reply(418, …)` on a route that never promised a teapot does not compile.

## text() <small>0.7.0</small>

```ts
({ text }) => text("pong")
```

Plain text. The status is the one `status()` set, or the usual one, unless given:
`text("gone", 410)`.

## html() <small>0.7.0</small>

```ts
import { html } from "@vxnsin/inkan";

app.get("/tea/:name", ({ params, html: page }) => page(html`<h1>${params.name}</h1>`));
app.get("/hi/:name", ({ params }) => html`<p>Hello, ${params.name}</p>`); // the same, returned as it is
```

HTML. The `html` tag escapes every value put into it, so what a user typed cannot become a
script on the page. Lists are joined, and `null`, `undefined` and `false` write nothing:

```ts
html`<ul>${teas.map((t) => html`<li>${t.name}</li>`)}</ul>${admin && html`<a href="/admin">admin</a>`}`
```

`raw(markup)` lets markup you made yourself through unescaped. Never use it for anything a
user sent.

## render() <small>0.7.0</small>

```ts
app.layout((content, { title }) => html`<!doctype html><title>${title}</title><main>${content}</main>`);
app.get("/", ({ render }) => render(html`<p>Tea, checked.</p>`, { title: "Home" }));
```

HTML in the layout of the route's scope, with the props handed to the layout. A plugin can
have a layout of its own; the closest one wins. Without a layout, the content goes out as it
is.

## redirect() <small>0.7.0</small>

```ts
({ redirect }) => redirect("/new")          // 302
({ redirect }) => redirect("/new", 301)     // or 303, 307, 308
```

Sends the client elsewhere. A location with characters a header cannot carry is
percent-encoded first.

## notFound() <small>0.7.0</small>

```ts
({ params, notFound }) => findTea(params.id) ?? notFound(`No tea ${params.id}`)
```

Ends the request with a 404 problem, the same one an unknown route gets, through
`onProblem` like any other. To end with another problem, throw one:
`throw problem(409, "taken", "That name is taken")`.

## setCookie(), clearCookie() <small>0.7.0</small>

```ts
({ setCookie }) => {
  setCookie("sid", session.id, { maxAge: 60 * 60 * 24, secure: true });
  return { ok: true };
};
({ clearCookie }) => clearCookie("sid");
```

A cookie on the answer; every cookie goes out as a Set-Cookie of its own.

| option | default | |
| --- | --- | --- |
| `maxAge`, `expires` | until the browser closes | seconds, or a date; `maxAge: 0` deletes it |
| `path` | `/` | |
| `domain` | | |
| `secure` | `false` | only over HTTPS; turn it on behind TLS |
| `httpOnly` | `true` | out of reach of the page's scripts |
| `sameSite` | `"Lax"` | `"Strict"`, `"Lax"` or `"None"`, which needs `secure` |
| `partitioned` | | |

## csv() <small>0.7.0</small>

```ts
app.get("/export", ({ csv, signal }) =>
  csv(rowsFromDb(signal), { filename: "teas.csv", separator: ";", bom: true }),
);
```

Rows as a CSV file, written as they come: an array, or a generator over a database cursor,
so a million rows never sit in memory at once.

| option | default | |
| --- | --- | --- |
| `columns` | the keys of the first row | a list of keys, or key → heading |
| `separator` | `,` | `;` for a German Excel |
| `bom` | `false` | `true` so Excel reads the file as UTF-8 |
| `filename` | | offered for download under this name |
| `guardFormulas` | `true` | a cell that starts with `=`, `+`, `-` or `@` gets a `'`, so a spreadsheet shows it instead of running it |

## Decorations

```ts
app.decorate("db", openDatabase());
app.get("/teas", ({ db }) => db.teas.all());
```

What [`decorate()`](/docs/api/app#decorate) puts on the context of a scope is there too,
typed.
