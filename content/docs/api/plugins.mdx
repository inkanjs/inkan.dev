## Plugins

```ts
import { compress, cors, rateLimit, serveStatic } from "@vxnsin/inkan";

app
  .use(cors({ origin: "https://shop.example" }))
  .register(rateLimit({ max: 120 }))
  .register(compress())
  .register(serveStatic({ dir: "client/dist", spa: true, exclude: ["/api"] }));
```

| | options |
| --- | --- |
| `cors(options)` (middleware) | `origin` (`"*"`, one, a list or a function), `credentials`, `maxAge`, `methods`, `allowHeaders`, `exposeHeaders` |
| `rateLimit(options)` | `max` per `window` (ms, default a minute), `key(ctx)` (default `ctx.ip`); per process |
| `compress(options)` | `threshold` (bytes, default 1024), `encodings` (`["br", "gzip"]`), `filter(contentType)` |
| `serveStatic(options)` | `dir`, `prefix`, `spa`, `exclude`, `immutable`, `maxAge`, `index` |
| `plugin(fn, { name?, shared? })` | makes a plugin; `shared: true` puts its hooks into the scope it is registered in |

## Problems

```ts
import { problem } from "@vxnsin/inkan";

throw problem(409, "taken", "That name is taken", { name });
```

`problem(status, type, detail?, extra?)` is an RFC 9457 problem document. Thrown anywhere on
the way, it becomes the answer, through `onProblem`. Its `headers` go out with it.

## Events

```ts
import { sse } from "@vxnsin/inkan";

app.get("/kettle", { response: { 200: t.events({ temp: t.object({ c: t.int() }) }) } }, () =>
  sse(async function* (signal) {
    for (let c = 60; c <= 80 && !signal.aborted; c += 5) yield { event: "temp", data: { c } };
  }),
);
```

`sse(source, { keepAlive? })` sends server-sent events from a generator. The generator gets
a signal that aborts when the client goes away; a comment keeps a quiet stream open, every
15 seconds by default.

## The typed client

```ts
import { client } from "@vxnsin/inkan/client";
import type { api } from "./server.ts";

const shop = client<typeof api>("https://shop.example.com", { headers: () => ({ authorization: `Bearer ${token}` }) });

const res = await shop.get("/teas/:id", { params: { id: 1 } });
if (res.ok) res.data.name;
else if (res.status === 404) res.problem;
```

`client<typeof app>(base, { fetch?, headers? })` knows every route of the app, with the
params, query, body and answers its contract names. Every failure is a problem document,
never a throw. See [Typed client](/docs/client).
